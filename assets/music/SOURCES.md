# Music Sources

All background music must be royalty-free and properly attributed here.

## How to add tracks

1. Download from one of these sources:
   - [YouTube Audio Library](https://studio.youtube.com/channel/UC.../music) (free, no attribution required for YouTube)
   - [Uppbeat](https://uppbeat.io) (free tier available, check license)
   - [Pixabay Music](https://pixabay.com/music/) (free, attribution recommended)
   - [Free Music Archive](https://freemusicarchive.org) (check individual licenses)

2. Rename the file descriptively: `lofi_chill_01.mp3`

3. Add an entry below:

## Tracks

| File | Title | Artist | Source | License | Attribution Required |
|------|-------|--------|--------|---------|---------------------|
| (empty) | - | - | - | - | - |

## Important

- NEVER use copyrighted music (commercial releases, recognizable songs)
- If attribution is required, add it to the video description in the pipeline
- lo-fi hip hop and ambient tracks work best for this format
